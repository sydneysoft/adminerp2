
## Instrucciones de despliegue
A continuación se listan los pasos a seguir para desplegar  el sistema:


- Primero se debe de correr el comando npm install para instalar todos los modulos de node

		npm install

- Luego se debe de crear un archivo **.env** en la raiz del proyecto copiando el contenido del archivo **.env.template**
- Posteriormente se debe de editar el contenido del **.env** cambiando las URLs y demas parametros respectivos dependiendo del entorno en el que se vaya a desplegar el sistema (localhost o producción)
